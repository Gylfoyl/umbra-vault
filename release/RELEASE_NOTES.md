# Umbra Vault 1.1.1

Сборка для Windows 11 x64. Установщик запускается от имени текущего пользователя.

Приложение, ярлыки Windows, установщик и README используют новый логотип Umbra Vault.

## Хранилища

- На стартовом экране можно выбрать папку и имя нового файла `.umbra` или открыть существующий файл.
- Каждый файл содержит записи, папки и пользовательские иконки своего хранилища и открывается собственным мастер-паролем.
- Кнопка «Закрыть файл» возвращает к выбору хранилища. Она доступна после завершения сохранения.
- Стартовый экран предлагает последний успешно открытый файл. При первом запуске после обновления он также распознаёт прежний файл в стандартной директории Umbra Vault.

## Папки

Правый клик по папке в боковой панели открывает команды переименования, выбора цвета и удаления. Доступны 12 цветов и вариант «Из темы». Названия и цвета входят в зашифрованные данные. Старые файлы открываются с исходным мастер-паролем. Для файлов с новыми цветами папок используйте версию 1.1.0 или новее.

## Проверка

Прошли 19 автоматических тестов, включая переключение между файлами с разными паролями, защиту от перезаписи, совместимость со старыми файлами, контекстное меню и сохранение цвета папки. Диалоги выбора файла и интерфейс папок проверены на Windows при масштабах Qt 100% и 200%. В версии 1.1.1 дополнительно проверены запуск установленной копии с новым логотипом и девять размеров иконки Windows.

Установленная версия открыла экран выбора файла без Python в PATH. Существующее хранилище осталось побайтно прежним после тестовой установки, запуска и удаления программы. Установщик без подписи Authenticode.
