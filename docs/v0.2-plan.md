# План Umbra Vault 0.2

1. Расширить модель записи идентификаторами иконки и акцента. Добавить каталог SVG, проверяемый импорт PNG/SVG и меню для выбранной записи.
2. Вынести оформление и параметры интерфейса в централизованные токены и локальные настройки. Добавить пять палитр, системный режим, сворачиваемую навигацию, плотность списка и Ctrl+K.
3. Проверить сценарии QML, повторный запуск, обработку недопустимых изображений и отрисовку на Windows.

Оформление встроенных образцов привязано к их постоянным идентификаторам. Настройки не содержат названий, логинов, паролей или заметок. Пользовательские демозаписи и их оформление существуют до выхода. Подключение настоящих данных описано в [отдельном этапе](secure-storage-plan.md).

## Результаты проверки

Прошли 10 тестов Python и QML. Проверены правая кнопка и Shift+F10, оба диалога оформления, поиск по каталогу, подтверждение удаления, дублирование, смена темы без перезапуска, повторное чтение локальных настроек, отклонение недопустимых изображений, автоблокировка и очистка буфера. В Python wheel проверены ресурсы приложения.

Замеры выполнены с оконной платформой Qt для Windows, Python 3.12.14 и Qt 6.12.0. Масштаб задавался через `QT_SCALE_FACTOR`. Память указана по рабочему набору при открытом образце из шести записей. CPU измерялся за три секунды простоя в процентах от одного логического ядра.

| Масштаб Qt | Показ окна, мс | RAM, МиБ | CPU, % |
| --- | ---: | ---: | ---: |
| 100% | 599 | 148,9 | 0,52 |
| 125% | 619 | 150,6 | 1,04 |
| 150% | 605 | 155,6 | 0,00 |
| 200% | 643 | 161,7 | 0,52 |

Результаты относятся к одному компьютеру. Наблюдение за CPU было коротким. Проверка экранного диктора и переключения DPI между мониторами остаётся отдельной задачей.
