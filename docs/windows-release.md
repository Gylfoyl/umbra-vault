# Сборка и проверка Windows

## Воспроизводимая сборка

Используйте Windows 11 x64, CPython 3.12.14 x64 и Inno Setup 6.7.4. Скачайте Inno Setup у издателя и проверьте цифровую подпись. Все версии Python-пакетов закреплены в файле сборки. [Официальные загрузки Inno Setup](https://jrsoftware.org/inno-setup/downloads)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r packaging\requirements-build.txt
.\packaging\build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

Скрипт проверяет тесты, генерирует многоразмерную иконку, собирает оконный EXE с отдельными DLL, создаёт установщик и вычисляет SHA-256. Параметр `-BundleOnly` останавливает сборку после создания папки `dist\UmbraVault`. Совпадение SHA-256 разных независимых сборок не гарантируется.

## Проверка на чистой системе

1. Возьмите чистую Windows 11 x64 со стандартной учётной записью без Python. Вычислите SHA-256 установщика и сравните с `SHA256SUMS.txt`. Тестовая сборка не имеет подписи Authenticode.
2. Установите программу с обычными правами в выбранную папку. Проверьте ярлык в меню «Пуск» и отдельно повторите запуск с включённым ярлыком на рабочем столе.
3. Выберите отдельную папку и создайте файл хранилища с тестовым мастер-паролем. Создайте и отредактируйте пароль и заметку. Проверьте тему, иконку, цвет папки, меню и генератор.
4. Завершите приложение и откройте снова. Проверьте отказ при неверном пароле, восстановление записей при правильном, удаление и сохранение результата. Проверьте Ctrl+L, автоблокировку и блокировку Windows.
5. Проверьте очистку скопированного пароля при неизменённом буфере и сохранение нового содержимого при повторном копировании. Проверьте интерфейс со 100%, 125%, 150% и 200% DPI.
6. Закройте первое хранилище и создайте второе с другим мастер-паролем. Проверьте независимость файлов. Переустановите программу, затем удалите её через «Установленные приложения». Проверьте удаление ярлыков и наличие обоих файлов. После повторной установки откройте оба хранилища.
