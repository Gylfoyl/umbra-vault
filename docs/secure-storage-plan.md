# Исторический план зашифрованного хранилища

Формат и автоматические проверки реализованы в 1.0.0. Требования к релизу исключили встроенные резервные копии. Актуальные гарантии описаны в [модели угроз](../SECURITY.md).

1. Определить формат и интерфейс хранилища в `app/storage`. Внешний заголовок содержит сигнатуру, версию, параметры KDF, случайную соль и nonce. Все значимые поля заголовка передаются AEAD как дополнительные аутентифицированные данные. Иконки, цвета и содержимое записей входят в зашифрованную часть.
2. Реализовать создание ключа из мастер-пароля через Argon2id в `argon2-cffi`. Ограничить параметры памяти, итераций и параллелизма до запуска KDF. Для шифрования использовать AES-256-GCM из `cryptography`. Для каждой записи файла брать новый 96-битный nonce из системного генератора случайных чисел.
3. Проверять размер файла до чтения, длины заголовка и полей, а также поддержку версии. Различать ошибки формата, чтения и записи. Для ошибки аутентификации сообщать, что пароль неверен или данные были изменены.
4. Писать только шифротекст во временный файл в том же каталоге. Синхронизировать запись перед атомарной заменой. Сохранять предыдущую шифрованную версию для восстановления. Определить поведение при параллельном открытии. При восстановлении сначала аутентифицировать резервную копию, затем явно подтвердить выбор пользователя.
5. Подключить создание и открытие файлов отдельно от демосессии. Выполнять KDF и файловые операции вне потока интерфейса. При блокировке выгружать данные, очищать принадлежащий приложению буфер, сбрасывать диалоги и игнорировать результаты фоновых операций предыдущей сессии. Проверить блокировку при событии сеанса Windows.
6. Добавить тесты циклов записи и чтения с кириллицей и вложениями, неверного пароля, подмены заголовка и шифротекста, чрезмерного KDF, неизвестной версии, уникальности nonce, прерванной записи и восстановления из копии. Проверить отсутствие открытых секретов в файлах и логах.

Подключение реальных записей требует прохождения этих тестов и проверки реализации. [Модель угроз](../SECURITY.md)
